# Starwish Homebrew tap

```bash
brew install --cask stary-pray/tap/pocket-chief
```

Installs [Pocket Chief](https://starwish.co.nz/pocket-chief/) from the official direct download. Apple Silicon, macOS 14 or later. The app keeps itself up to date; `brew upgrade` is not needed.

The cask is updated automatically when a release is published. Please report problems at https://starwish.co.nz/pocket-chief/.
